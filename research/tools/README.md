# Инструменты разбора

Оба скрипта работают с результатом `download_file_content` Google Drive MCP —
это JSON вида `{content: <base64>, id, mimeType, title}`.

- `reademl.py <файл.json>` — печатает тему, отправителя, дату, тело text/plain
  и список вложений письма .eml.
- `extract.py <файл.json> <каталог>` — извлекает вложения письма в каталог.

Крупные файлы (примерно от 40 КБ) MCP сам выгружает в файл tool-results, и путь
указан в тексте ошибки — его и подавать скриптам. Мелкие приходят строкой base64
прямо в ответ; в облачной сессии их прочитать нечем (см. HANDOFF.md).

## Реестр онлайн-источников

- `online_resources_data.py` — сам реестр: около 310 генеалогических ресурсов из «Сводного
  реестра онлайн-источников» (Пикабу, части 1–3). У каждого указано, что в нём есть,
  какой доступ и чем он полезен нашим ветвям. Новые источники добавлять сюда.
- `build_online_resources.py` — собирает `research/online-resources.json` и
  `research/online-resources.md`. С ключом `--check` проверяет, отвечают ли ссылки,
  а для не ответивших ищет копию в web.archive.org. Проверка занимает около 10 минут.
